# Security Policy

## Supported Version

Only the current `main` branch is supported for security fixes.

## Reporting

If you find a vulnerability, do not open a public issue with exploit details.

- Contact: `yosoyvargas@hotmail.com`
- Subject: `Cine Posta security report`

Include:

- a short description of the issue
- affected URL, file, or feature
- reproduction steps
- impact assessment if known

## Scope Notes

- This site is published as a static site on GitHub Pages.
- Public frontend keys that are intentionally marked as publishable are not treated as secret credentials.
- Security-sensitive infrastructure or admin credentials must never be committed to this repository.
