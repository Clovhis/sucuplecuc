# Explosiometro

El Explosiometro mide quilombo de accion, no calidad: tiroteos, persecuciones, peleas, explosiones, batallas y set pieces.

## Criterio

- Las peliculas con datos externos confiables usan override curado en `src/lib/explosiometro.ts`.
- La base mas objetiva son conteos publicados de AOBG cuando existen.
- Cuando el quilombo no se explica por muertes, se usan fuentes de produccion o critica sobre densidad de accion, stunts, persecuciones y efectos practicos.
- El resto de las peliculas de Accion cae en un fallback heuristico basado en categoria, generos, review y sinopsis.
